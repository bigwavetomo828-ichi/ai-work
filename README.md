# AI実践ワーク

index.htmlをダブルクリックしてブラウザで開きます。インターネット接続なしで動きます。

1. 希望・困りごと・使う人・大切にしたいことを入力。
2. 自動案内、または01〜10と11その他のカードを選ぶ。未定なら00。
3. 追加の希望を入力し「回答をプロンプトに反映」。
4. コピーして使うAIの新しいチャットに貼る。テキスト保存も可能。

入力内容はサーバーへ送信・保存しません。タブを閉じると失われるため、残す場合はテキストで保存してください。テーマ判定はキーワードによる簡易案内です。作業の実行は接続するAIのツールと権限によって異なります。

## GitHubに保存する方法
このフォルダのindex.htmlとREADME.mdを、保存したいリポジトリにアップロードできます。回答ファイルや個人情報は含めないでください。公開サイトとして使う場合はGitHub Pages等の公開設定が別途必要です。
